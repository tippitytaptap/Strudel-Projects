# My Strudel Project

A collection of live-coded music patterns made with Strudel.

## About
I want to show everyone that music can be accessible with simple beats. 

## How to use
1. Open a pattern file from the `patterns` folder.
2. Copy its contents.
3. Paste it into the editor at https://strudel.cc and press Ctrl+Enter to play.
